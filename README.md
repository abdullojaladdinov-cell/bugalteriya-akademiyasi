# Bug'alteriya Akademiyasi

Bu loyiha accounting/finance ta'limi uchun landing page va ro'yxatdan o'tish tizimidan iborat.

## Ishga tushirish

```bash
python server.py
```

Keyin browserda quyidagi manzilni oching:

- `http://localhost:8000`

## Xususiyatlar

- Kurslar haqida ma'lumot
- Ro'yxatdan o'tish formasi
- Mijoz ma'lumotlarini saqlash
- Admin paneli
- CSV export
